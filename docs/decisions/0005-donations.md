# 0005: Revenue comes solely from donations

- **Status:** Accepted, 27 October 2026. For whose name hosts the page, the
  second channel (Buy Me a Coffee), and when it transitions to an entity:
  [0017](0017-personal-sponsors-page.md).
- **Decision:** TotalDrop remains free: no advertisements, no paid tier, and
  no investors. Donations are accepted transparently (starting via GitHub
  Sponsors and Buy Me a Coffee per [0017](0017-personal-sponsors-page.md)).
  Every cost item and monthly income/expense statement is published line by
  line on `totaldrop.app/donate` (and in [donation-ledger.md](../donation-ledger.md)).
- **Why:** There is never pressure to monetize user metadata or push users
  into a paid tier. Transparent public accounting builds trust and keeps
  operations lean.
- **Consequences:** Donations never buy features, priority, or governance
  weight. Whenever a new recurring cost is proposed, the donation page and
  ledger must be updated before incurring it.
